# ios_final — Weather (Open‑Meteo)

Учебное iOS-приложение под финальные requirements: Storyboard + AutoLayout, TabBar + Navigation, UITableView с кастомными ячейками, Networking (URLSession), Local Storage (UserDefaults), UX-фичи (loading, pull-to-refresh, анимации), Unit Tests (XCTest).

## Запуск
- Открой `final.xcodeproj`
- Выбери схему `final`
- Run на симуляторе/устройстве

## API
Используется Open‑Meteo (без API‑ключей):
- Geocoding: поиск города по имени
- Forecast: текущая погода + hourly + daily

## Что будет в приложении (модули)
- Today: текущая погода в выбранном городе
- Forecast: прогноз (таблица/детали)
- Favorites: избранные города (UserDefaults)
- Settings: настройки (UISwitch/UISlider/UISegmentedControl)
